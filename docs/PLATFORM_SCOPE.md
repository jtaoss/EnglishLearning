# 当前平台范围

2026-11-08 用户明确确认：**恢复 Windows + Android 持续开发**。Windows 是主学习平台，Android 是移动复习平台，共用 Flutter 业务代码、稳定词条 ID 与 SQLite 数据约定。此决定更新早期“仅 Windows、Android 暂停”的范围；历史验收报告保留原结论，不倒改历史状态。

当前 0.5.0+8 增加 Android 安全凭据适配并完成实体手机隔离验收，没有回退 P1-B～P2-B1 成果。2026-11-09 用户进一步确认：Android 不需要手动导入/导出功能，界面取消 CSV 入口；Windows 保留 CSV 导入。

## 共用与平台边界

- 共用：CSV 校验、稳定 ID 去重、词库和学习模型、复习日期、词义/发音状态分离及离线 SQLite。
- Windows：现有 WinCred、Notion 只读词库同步及模拟事件实验继续保留；P2-B1 副本能力不自动迁移正式库。
- Android：使用既有平台配置与原生插件，复用只读同步逻辑，Keystore 独立保存凭据，不复制 Windows 凭据。已独立授权只读集成，电脑只读验证返回 200；手机真实请求失败／超时，用户决定稍后同步，正常应用仍为 0 词。隔离 HTTP 测试不代表真实 API 直连验收。
- 云端：长期以 Notion 为主词库和学习记录中心，无自建服务器。正式真实事件的 1～3 条试写仍按 P2-B1 方案等待另行明确确认；恢复双平台开发不等于批准正式事件写入。
- 发音：继续自然拼读与合法标准音频，不引入 IPA 或中文谐音。六词实际 Android 播放完成，用户确认声音正常；不重开发发音模块。

## 本轮与后续边界

已在 Android 16 / API 36 实体手机的独立包中验证 100 词去重、答案揭示和评级、进程重启后的 SQLite、六词音频与独立自评、安全存储、真实后台切换及连接失败。Android 系统文件选择按用户最新要求停止验收，不标记通过。不启动模拟器，不导入完整 5,552 词，不复制 Windows 个人数据库到手机。

后续在用户恢复工作且手机网络就绪后继续真实 Notion 直连验收，无需重复输入当前手机已保存的凭据。账号系统、多设备冲突合并、后台服务器和真实历史批量上传均不属于本轮。P2-B2 正式事件试写仍未获授权。
