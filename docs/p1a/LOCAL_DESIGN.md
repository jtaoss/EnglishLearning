# P1-A 本地数据与验收约定

设计日期：2026-11-07。本文件是环境安装期间的准备，不表示功能已经实现。以双平台实际构建结果为进入条件。

## 页面与导入范围

沿用首页、设置、主题与 go_router，增加词库页和词卡页。首页提供显式的“导入 100 词 CSV 样本”入口，不在启动时自动导入。样本只使用已有 preparation CSV，保留文件校验值和原始稳定 ID；不访问 Notion，不导入完整 5,552 词。

词库能够区分主学习、扩展、暂缓，默认学习入口使用主学习，暂缓词只作为已保存的候选内容查看，避免误加入复习队列。英文列表不直接展示释义。词卡默认隐藏答案，查看后才允许掌握、眼熟或遗忘；换词重新隐藏，保存过程中禁止重复提交。

样本的 100 个词头已核验，但释义仍待复核，页面应保留这个提示，不改成“官方释义”。来源、页码、原书分类与两个 PETS 年份归属保存在词条内容中。初次导入的学习和发音状态均为未测试；已有状态不受重复导入影响。

## 数据边界

| 数据 | 主键/关联 | 内容 |
|---|---|---|
| vocabulary | 既有 entry_id | 英文、中文释义、原书分类、来源文件/ID/页码、核验状态、释义复核状态、2015/2025 官方归属、学习词库分类 |
| learning_progress | entry_id 外键 | 掌握状态、发音状态、复习次数、最后复习 UTC、下次复习 UTC |
| review_events | 本地递增事件 ID + entry_id 外键 | 本次选择、发生 UTC、计算后的到期 UTC，作为本地审计记录 |

词库刷新仅更新 vocabulary，不覆盖 learning_progress，不删除历史事件。一个 ID 对应不同词头、同一完整词头（保留大小写）对应不同 ID 时拒绝整批并报告冲突，避免悄悄合并学习记录。数据库采用版本号、外键和事务；发现比应用更新的 schema 时明确报错，不自动重建或删除。

Repository 暴露异步导入、读取和记录评分接口；页面不直接写 SQL。数据库任务放到后台 isolate，单次事务中完成评分事件和进度更新。原生句柄不跨 isolate 传递。路径选择限制在平台存储适配层，Windows/Android 共享数据与复习业务。

## CSV 校验

支持 UTF-8 BOM、CRLF/LF、引号内逗号和换行、双引号转义。表头必须唯一且包含已约定字段。拒绝空 ID、空词头/释义、未核验词头、非法词库分类、重复 ID、行列错位和不闭合引号；先校验完整批次，再在事务中导入。P1-A 单次最多 100 条，不能把导入按钮用于全量导入。

## 基础复习规则

P1-A 使用明确且可测试的固定间隔：遗忘 10 分钟、眼熟 1 天、掌握 7 天，从本次评分时刻计算。此规则只是最小学习闭环，不宣称是成熟 SRS 或考试概率。时间以 UTC 保存、按本地时区显示；未测试词没有伪造的上次复习时间。到期筛选包含未测试的主学习词和已到期的主学习词，扩展/暂缓分类不自动混入。

## 必须验收的行为

- 真实 SQLite：100 条首次导入、重复导入仍为 100、按 ID 更新释义后个人状态与事件不变、非法批次与 ID/词头冲突整批回滚。
- 重启：实际磁盘数据库关闭并重新打开，数量、评分、发音状态和 UTC 时间仍一致。
- 业务：三种间隔与跨日/时区计算、未知 ID 拒绝且不产生事件、事件和进度同事务保存。
- 页面：答案默认隐藏、查看答案前评分不可用、换词隐藏、保存时重复点击不会重复记账、窄窗口和大字体可操作。
- 原生：Windows Debug/Release 和 Android Debug APK 包含 SQLite 运行库；Windows 首次真实运行验证导入、学习、重启及离线持久化。Android 没有真机时明确保留运行未验收状态，不要求模拟器。

## 依赖选择依据

准备使用 sqlite3、path_provider 和必要的 CSV 解析能力；只新增服务于本地存储/导入的依赖。具体版本和锁文件差异在实施时记录，不运行无关 pub upgrade。

[sqlite3 官方包文档](https://pub.dev/packages/sqlite3)说明其 native hooks 支持 Windows/Android，并随应用打包 SQLite；[构建钩子说明](https://github.com/simolus3/sqlite3.dart/blob/main/sqlite3/doc/hook.md)说明预编译二进制有随包发布的 SHA-256 校验。[path_provider 官方包文档](https://pub.dev/packages/path_provider)提供两平台的应用支持目录。CSV 必须按本项目更严格的错误策略校验，不能把解析库宽容处理的损坏输入直接写入数据库。

后续发音模块独立保存自然拼读提示、标准音频来源及授权；Notion 同步以后再实现，不改变本地稳定 ID 或以词库内容覆盖个人进度。

首轮测试修正：May/may、March/march 在原数据中具有不同 ID 与词义，必须独立保留。大小写不归一化用于去重，原始 CSV 不改动。
