1. 已核对的 553 个词和原有 500 个词不再创建。续传必须使用现有检查点，不能清空或换一个新检查点。

6. 防重复依靠检查点状态、创建前的稳定 ID 查询，以及结果不明时不重发。已核对 ID 不进入创建队列。
7. 进度继续写回 `private/p5c/p5c4c-checkpoint.json` 和同名审计日志。查询失败或连接中断时从同一检查点恢复。出现冲突、拒绝、重复 ID 或新的额外页面时停止，不回滚已创建页面。
