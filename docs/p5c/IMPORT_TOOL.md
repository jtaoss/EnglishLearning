# P5-C.4A 导入工具与离线验收

版本保持 0.7.0+10。本轮没有正式云端写入。内容写入 0，事件上传 0，个人 SQLite 未打开。

## 工具

独立命令是 `scripts/p5c/import_vocabulary.py`，实现在 `scripts/p5c/vocabulary_import.py`。Flutter 学习界面没有批量上传。

默认是 dry-run。写入同时需要下面全部条件，缺一项就在打开写入凭据之前停止：

- 命令显式使用 `--mode write --phase trial10` 或 `--phase full`。
- 授权文件同时给出确认语句、正式清单 SHA-256、新增队列 SHA-256，以及下面 10 个试写 ID。
- 环境变量 `ENGLISHLEARNING_P5C4_WRITE_AUTHORIZATION` 的值是 `authorize-p5c4-notion-vocabulary-write`。
- 写入凭据使用新的 Windows 凭据名 `EnglishLearning.Notion.VocabularyWrite.v1`。现有只读凭据和事件沙盒数据源都会被拒绝。
- 检查点文件不能放在个人应用数据目录，也不能使用 SQLite 后缀。

创建请求只发 `POST /v1/pages`。程序没有修改或删除请求。每个稳定 ID 先查询；只有确认云端不存在后才创建。返回成功后还要再查询 29 个内容字段和 2 个新增审计选项，一致才标为完成。超时、断线、529、5xx 或响应无法读取时标为待对账，再查询一次；查不到就停止该 ID，不自动重试创建。429 且 Retry-After 不超过 10 秒时，先确认页面没有创建，然后最多再试到 3 次；等待时间更长就停在未发送完成状态，留待下次恢复。

每批 10 条，请求间隔 350 毫秒。新增页写入 29 个内容字段，并只追加 `原5552台账内=是`、`发音资源状态=未配置`。另外 7 个已有审计属性不进入创建载荷。个人评级、复习日期、发音自评和学习事件不进入载荷。已有页面不更新，因此现有审计属性和个人字段不会被清空。

## 正式导入前检查

1. 用户单独授权 P5-C.4B，只允许创建下面 10 个新词。
2. 另建只含 Read content 和 Insert content 的集成，只分享正式词库；不要给更新、删除或事件库权限。
3. 把该集成存入 `EnglishLearning.Notion.VocabularyWrite.v1`，JSON 只含 `token` 和正式数据源 ID。不要复用只读凭据，也不要把 token 写进仓库、日志或聊天。
4. 授权文件重复正式清单 SHA-256、新增队列 SHA-256 和 10 个试写 ID。
5. 确认 dry-run 仍是新增 4,832、更新 0、冲突 0，云端仍是 500 页。
6. 194 个待核实词和 27 个暂缓词仍不在正式清单中。
7. 个人 SQLite 哈希仍是上面的恢复快照。

## 风险和回滚

Notion 文本字段本身不保证 ID 唯一，所以同一 ID 出现两条页面时程序停止，不继续创建。响应丢失时，本地只记录待对账，不能把“请求已发出”当成成功。

程序不能删除云端页面。试写结果不对时，先停止，保留检查点和审计日志，由人工在 Notion 中归档那 10 页；不要启动全量导入。已有 500 页没有更新请求，个人学习库也没有被打开。待对账的 ID 在确认云端结果前不会自动重试。

本轮到此停止，等待单独的 P5-C.4B 写入授权。
