只接受页面 ID `414cd5b5-d6b9-80db-ac03-d94e99d65e61`。它必须同时满足：未归档、词头为空、稳定 ID 为空，并且除「学习词库分类」为「主学习」外，29 个内容字段和 9 个审计字段都为空。

## 模拟测试

`scripts/p5c/test_vocabulary_import.py` 共 19 项，19.939 秒内通过。模拟使用内存中的 Notion 替身和检查点副本，不访问正式库写入接口。

覆盖的情况：

- 在真实检查点副本上，4,277 个未发送 ID 按正式清单顺序进入队列。
- 处理完第一批 10 个后中断，再次运行时不重复创建这 10 个。
- 下一个词收到 HTTP 429 后按 Retry-After 重试一次，并只保留一页。
- 再下一个词响应丢失后停在待对账，后续运行不再创建它。
- 已核对页面和原有 500 页不会进入创建调用。
- 已知空白页不计入成功词条；再出现另一张无稳定 ID 的页面时，结果是 `blank_page_refused`。
- 第二个写入实例拿到 `writer_already_running`，创建次数为 0。写入锁在进程结束后释放，避免把一次崩溃变成永久锁。
- 测试前后个人 SQLite 的字节指纹一致。

没有把 4,277 个词全部提交到模拟服务。安全队列是整份核对的；断点、限流、丢响应和重复运行是在这份真实队列的前几批上执行的。
