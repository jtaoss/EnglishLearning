# P6-C.3 核心释义质量规则 V4

状态：AI 质量建设规则候选；基于 V3 增补，不修改正式词库、不构成人工签审。适用本次 500 词验证及将来经授权的批次；本轮不得运行剩余 4,832 词。

## 1. 四种计量单位分别保存

- **原始片段**：原字段中的完整文本及位置，稳定片段 ID 不能为便于展示而改号、拆碎或改写。
- **英语用法单元**：具体词性、对象、搭配、论元方向或语域，由对应词典证据支持。一个片段可能涉及多个用法，多个片段也可能是同一用法的中文改述。
- **展示组**：首次记忆、常用扩展或其他层中的教学安排，不自动等于英语词义数。
- **词典补充候选**：原片段无法支持的新内容，单列来源、采用状态及教学建议，不自动进入任何正式原文层。

不以原文片段覆盖 100%、展示组数量、压缩率或置信度单独证明语义质量。原始 500 词的 1,216 片段、688 核心组是文本/展示计量，不是准确率或学习效果。

## 2. 原片段与用法允许有证据的一对多映射

V3 已区分片段与用法；实施校验不能又把它们强制为一次性分配。

1. 旧片段及其唯一 ID 仍只在原始台账出现一次；展示/用法映射可以引用同一 ID 多次。
2. 重复引用必须提供 `semantic_splits`：被引用片段、AI 拆解说明、各用法词性、具体证据。不得复制成两个“原文片段”。
3. 校验分为两项：原始唯一片段集合完整；每个引用对应的用法有证据。不能靠取消重复引用校验就放行任意映射。
4. 逐义词性未标时，原始对应保持未知；词典支持的推荐词性和原书实际标注分开。不要靠片段顺序把一个分给名词、另一个分给动词后就声称穷尽。
5. `import` 是本轮确认案例：原“进口”需要容许贸易动词与名词行为分别引用；数据输入另列。名词进口品定义不能证明进口行为，进口品仍须作为独立补充候选。
6. `forecast`、`decrease` 的现有词性推荐并非因未穷举所有中文词/POS组合就错误。只在重要用法确实没有被展示、子义或明确提示表达时计漏义，不能机械要求笛卡尔积。

## 3. 逐用法证据与中文提示相互对应

- 每个用法引用具体定义或出版社观察，说明是同义、语境收窄、上位概括还是有待补证；不能只引用“该词出现过”的网页。
- 词典项的主语、宾语、施受方向、对象限制和词性需要吻合。引用同词头不等于引用正确用法。
- 可以简洁，但会造成不同语义误读时应补对象。`indicate` 的指向对象、信号表明和简要陈述不能只挂前后两个词典项而称所有指示语境均已支持。
- `usage_note`、`core_explanation`、原子义项及分层需要一起审查。已经由现有说明限定的裸原文警告，不重复算当前错误；如需要短显示也带限定，可记录教学建议而非伪造新错译。
- 中文同字不等于英语同一语义。也不能因为 WordNet 有两个 synset 就强制拆成两组核心；一个展示框架可并列用法，只要区别和映射保留。

## 4. 核心选择与重要用法覆盖分别评价

通常 1–3 组，不设硬上限。先检查不同核心功能，再安排教学层级；扩展层表示后学建议，不代表低频。

分别回答：

1. 现有核心有没有错译、错误合义、错误词性或重要用法未被表达？
2. 原始释义本身是否缺少重要用途？例如 `management` 的管理活动不能代替管理人员这一群体。
3. 该用途是否已经是旧词典候选？已跟踪的缺口不能重复计作本轮新漏报，也不能因已登记就当它已经获准采用。
4. 新查到的是重要独立用途，还是专业义、范围提示或教学偏好？不得为追求“全面”穷举所有生僻词典项。

词典可证明用法存在和语义边界；重要性、首次记忆层级通常仍是明确标注的教学判断。没有语料数据就不声称最常见、考试高频或 PETS-3 官方重点。教材词头频率不能证明具体义项频率。

## 5. 外部补充的四个状态

`发现 → 词典证据核验 → 采用/不采用裁定 → 教学层级裁定` 分开保存。存在性可核验，不等于已采用或有唯一排序。

- `source_sense_ids=[]`，禁止挂到不包含该内容的原片段上充数。
- 采用前始终 `AI_candidate_not_adopted`、`human_approved=false`，不能自动升级到核心。
- 旧 55 条补充候选、其中 23 条核心层建议的原状态保留。本轮另发现 21 条候选，不自动写入旧文件。
- 相同中文字符串不是去重依据。`reference` 的参考书和引文出处不同；`nuclear` 的核能已在旧限定中，不应重复算全新缺口。

## 6. 盲审与对照严格分阶段

1. 固定抽样计划、原数据哈希、规则版本和范围。
2. 新上下文先只给词头、原词性、原始完整中文、原片段及不经过旧结论挑选的合法词典证据；不透露旧核心、严重级别、风险标记及旧审查说明。
3. 独立提出核心/扩展/其他/暂存/补充，分批保存；失败有限重试，如实保留不可访问来源。
4. 验证映射及输入哈希，封存提案哈希后才向对照阶段提供旧候选。封存后不得要求盲审者为了迎合旧结论重写。
5. 对照者必须说明非盲身份。机械分层、字面显示和语义争议分别记录；差异不直接计作错误。
6. 配置模型名、实际后端快照、原生成后端身份分别记。原后端未知时，不能称已证明不同模型验证；本轮只证明新上下文及配置为 `gpt-6-astra` 的两项审查任务。
7. 不相交的 45+45 词不能用于计算同词双审者一致率。不可见 token、费用、API 次数用 null，不能将检查点文件数当调用数。

## 7. 问题级别、证据状态与问题域分开

- **Critical**：会导致系统性严重误学或破坏来源/身份等，必须有具体证据，不能仅按原高风险标签推导。
- **Major**：重要独立用法缺失、明显错译/合义或词性冲突等，足以影响目标阅读/表达理解。注明属于当前候选还是原文覆盖缺口。
- **Minor**：局部用法证据不齐或中文范围提示不清，但没有证据证明整体错译。
- **Info**：材料或流程提示；教学层级、同义改述和排序偏好另计，不混入错误总数。

每条确认问题记录证据、观察、问题域、实际影响、处理状态、是否漏义/词性混淆。错误数量不是旧 `Major` 标签数量；盲审模型只看过原文时，它标出的源材料问题不能直接算对旧候选的裁定。既有暂存或已有限定的处理仍须纳入上下文。

本轮确认 0 Critical、2 Major、1 Minor：Major 包括 `import` 当前候选漏用法及 `management` 原文覆盖缺口；不能描述成两处原文错译。未确认词性混淆，也不据此证明全 500 词无词性问题。

## 8. 分层抽检与放行标准

- 高风险定向复核加独立分层抽检，固定选择方法并记录总体及配额；禁止挑选容易通过的词或按置信度筛选。
- 本轮 42 个旧 Major 全检，另抽 48 词，其中 24 个原 standard 风险、24 个其他非 Major 的 high 风险。抽检发现两项 Major，均原标 Minor/high；standard 子样本未发现已确认问题。不能据目的性过采样计算总体错误率或准确率。
- 对漏报类别查原因，修规则后只在已有 500 范围验证，再决定是否请求下一阶段授权。
- 未解决 Critical 或同类系统性 Major 不能直接全量推广；修订候选文件存在不等于问题已关闭。
- 原 100 词的 48 个高风险/暂存项目继续待审；原 500 的 342 个宽泛高风险标签不自动清零，也不是 342 个已证实错误。
- 其余未重审 410 词保持旧状态。没有人工金标准不报准确率提升；没有学习实验不报记忆效果提升。是否需要专家裁定按实际争议确定，不把初学者没有能力裁定当作伪造已签审的理由。

## 9. 不变性、权限与复现

所有修订写独立文件，记录前后差异、候选哈希、原数据字节哈希、原字段 canonical hash 和封存盲审记录哈希。原文、稳定 ID、旧 100/500、正式 5,332、个人 SQLite/side files 均不得改写；不连接 Notion，不上传事件，不发布 UI。

处理脚本只组装已经保存的审查决定，不在普通构建/校验中调用模型或抓取词典。合法 WordNet 按既有许可引用；商业网页仅保存短篇自写观察与 URL。403 不绕过、不冒称读取成功。共享工作区若有其他任务修改日语模块，记录外部变动，不覆盖、不恢复、不混入本轮候选。

本轮结论 **B**：先在现有样本修正规则并验证；不是全量处理授权。完成即停止。
