# P6-C.4 修订 V4：用法覆盖矩阵与保守分层

版本：P6C4-V4.1。状态：AI 工作规则，未人工签审。继承 P6-C.3 RULES_V4，原文件不改。本规则及 GATE_PROTOCOL.json 在本轮结果产生前封存；不能看完结果后降低门槛。

## 修订前后差异

| 问题类型 | 原 V4 已有要求 | 本次可执行修正 |
|---|---|---|
| 原片段与英语用法混同 | 允许有证据的一对多 | 每词填写用法覆盖矩阵：原片段、实际用法、词性、主宾语/对象、证据、候选所在层；不是只校验片段集合 |
| 多词性按原片段位置分配 | 原文对应未知须保留 | 源词性与推荐词性分开；每个源词性有明确覆盖或未覆盖理由，不要求所有中文与所有词性笛卡尔积 |
| 原文缺独立用途 | 补充候选分离 | 双轨检查：原文的内部覆盖 + 词典中的重要独立用途缺口；发现缺口必须显式挂风险和候选，不假装核心已经完备 |
| 中文近义掩盖用法区别 | 引用具体定义 | 合并前检查对象、方向、词性、语域；同框并列可以，但用法边界与逐义证据不能消失 |
| 层级与实际频率混淆 | 后学不等于低频 | 每词写首次记忆选择理由；没有语料统计时只写教学建议；不得按 WordNet 顺序、教材词头频率排义项 |
| 原文有疑点 | 进入暂存区 | 暂存不等于错误/罕见；源证据未定时不进入已确认其他义，也不因新模型赞同而清历史风险 |
| 无意义的重复改写 | 保存新候选 | 回归时优先保留已正确组，只为有依据的问题改组；其余写复评观察，显示偏好不当错误 |
| 错误关闭管理 | 候选与人工分开 | 区分“候选用法修正已验证”“缺口已显式识别但采用待决”“源原文已修正”；后两者不能冒充原文问题消失 |

## 1. 不可变原文与四种单位

原始29字段、稳定Word ID、词头大小写、完整中文、各片段ID及Unicode位置保持不变。原始片段、英语用法、展示组、外部候选四者分开。一个原片段可对应多个有证据的用法，但必须显式标记AI拆解；多个同义中文可对应一个用法。

仅以原片段守恒不能证明用法完整。也不能因词典有多个synset就强制首次背诵所有细分。

## 2. 每词的用法覆盖矩阵

至少记录：`use_id`、`source_sense_ids`、推荐词性、中文提示、语义角色/对象、证据ID、所在层或暂存原因、证据关系。外部候选的`source_sense_ids=[]`，另外挂到矩阵，不能借一个宽中文词偷渡新义。

- 源逐义词性未知时，原始字段继续为未知；推荐标签来自英语词典证据，不来自中文片段顺序。
- 同一原片段重复引用时，`semantic_splits`逐用法解释原因和引用，不制造新的原文ID。
- 每个源词性有覆盖、候选缺口或不确定状态；禁止默认“名词给第一段、动词给第二段”就完成。
- 不要求机械组合所有中文和词性。已经准确表达的名词/动词可原样保持。
- 把使动/自身变化、给予/接受、过程/结果、活动/人员、实体/信息、具体/比喻等作为检查维度；仅在词典与原文支持时拆解，不自动生成每种对立。

## 3. 核心、扩展、其他、暂存

核心通常1–3组，无硬上限。优先首次理解所需的不同功能，中文自然、简洁、带必要对象；近义可合并，跨词性不合组。不同核心用途可同框并列，但子用法、方向和引证独立保存。

扩展是后学建议，不代表低频；其他必须有专业、地区、语域或语境限制，不能因为字数多就移到其他。未知原文应暂存，不伪装成已经证实但罕见的用法。

检查首屏是否把一个专门或有条件的读法放在没有条件的一般义之前；如果没有可靠频率依据，不宣称唯一正确排序。超过3组触发人工/独立语义复核，不以删重要义满足数字。

## 4. 双轨覆盖：原文与重要外部用途

轨一检查原文所有片段在层级或暂存中可追溯，词性/对象/方向正确。轨二检查可靠词典是否有原文未明确表达、对生活/阅读/职场理解有独立价值的用途。

新用途的存在、其重要性、采用与层级是四个不同判断。词典证明存在与语义边界，不自动证明频率。重要性判断明确标为教学AI建议，可争议、可待审。

已有候选不重复算新漏报；原文外新用途只进入`dictionary_additions`，状态`AI_candidate_not_adopted`，不自动升级核心。必要时写`core_coverage_incomplete_pending_addition_decision`，避免候选虽在附件但主记录假称完备。

## 5. 证据与中文改述

逐用法核对词性、对象、主宾语方向、过程/结果以及语域。选取具体synset/出版社观察；同词头或同词性的一大串引用不等于逐用法支持。一个商业网页只留短篇原创概述和URL，不复制整页或大量例句。

保守使用“兼容”“有条件支持”“宽义改述”“证据不足”。单一词典未收录不等于否定；访问失败如实记录。中文同义提示的限定应与usage_note一起读；原模型已经限定的源警告不重复计当前错误。

不显示国际音标、不用中文谐音；本轮不处理发音资源。WordNet许可沿用项目记录，无未授权商业资源抓取。

## 6. 历史状态与回归

已有500词只产出对照。最初100中的48个历史高风险词逐一记录本次观察和旧待决事项，保留`historical_risk_retained=true`及人工待审；不能因模型认可、结构通过或换版本而自动解除。

新增或变更的组应检查没有挤掉旧正确用法，原片段全部保存。原始500与新100两个集合严格分离；新100不成为正式600词发布数据。

## 7. 盲审、错误与放行

新100的生成记录先封存。独立审核上下文只收到原词头、源词性、完整原文、合法证据和本规则；不收到生成答案、旧结论、风险或严重级别。其提案也封存后再比较；不为附和生成答案回写盲审。

实际后端不明时只声明独立上下文，不声明不同模型。记录真实可见模型配置与不可见的快照、用量/费用null，不伪造调用或人工意见。

证据支持的Critical/Major/Minor与AI风险、教学偏好分别统计。覆盖缺口分为：当前候选漏原文支持的独立用途、原文未含但外部词典有的重要用途、已跟踪候选待采用。后两类若已显式标记和单列，不等于当前生成器又偷偷丢了原义；仍不能写成已人工解决。

本轮放行严格使用预先封存的GATE_PROTOCOL.json。通过仅允许建议后续扩大隔离候选处理，不允许自动运行剩余4832词、写Notion/SQLite或发布UI。
