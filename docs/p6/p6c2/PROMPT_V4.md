# P6-C.2 500词候选提炼与分层审查规则 v4

本文件是本轮 Codex 会话的可审计工作规则，继承 RULES_V3；不声称是某次外部 API 请求的逐字提示词。精确后端模型与会话计费 token 未暴露，必须留空。

1. 原100词只包装独立复核后的版本，完整嵌入既有提炼与复核记录，不重生成或改写。
2. 新400词严格来自已冻结选择表；每50词保存明确的逐词AI决定。标点切片只是可追溯原文单位，不能作为自动语义分组或首次记忆排序规则。
3. 每个原文片段恰好进入一个核心/扩展/其他组或原文疑点保留区；来源中文、字符区间、原词性证据、源29字段哈希始终保留。
4. 同义近义压缩必须明确指定；不同语义和不同词性不得当同义合并。核心通常1–3组，重要多义不受硬数量限制。
5. 精选WordNet 3.1具体义项只支持词义/用法相容，不支持语料频次、词典排序或官方PETS重点。原文词性未分配时保留未知，词典支持的推荐词性标为AI建议，不冒称原书对应已查清。
6. 无法可靠独立教学的原文保留为reserved_original_items；不偷偷放其他层当罕见但已确认义项。首次背诵显示与原文本身须区别。
7. 原文外常用义只作为有来源dictionary_additions候选，source_sense_ids为空，不进正式核心，不升级人工签审。
8. 完成结构审查后逐词进行语义检查并保存具体结论；高风险以新一轮从原文和原始词典资料出发的复核保存。相同会话的非盲复核不能冒充独立模型或真人。资料不可用需记录未完成及原因，不能用模板造出审稿结果。
9. Critical=数据丢失/源或ID错配/虚构证据等阻塞，Major=实质语义、词性、范围或重要遗漏，Minor=展示措辞/可读性，Info=教学顺序未经语料验证等提示。发现数量与已修正/仍开放数量分开统计。
10. 所有结果AI_candidate、human_approved=false、needs_human_review=true；结构PASS或AI复核不是人工签审，也不是准确率或学习效果实验。
11. 只写p6c2独立输出及对应脚本/数据契约测试；不连接Notion或SQLite，不改正式词库、原100词、日语或正式学习界面。保护基线漂移须停止，不自动修复原数据。
