# P6-C.1 后续提炼规则 v3

本文件是此次复核后形成的工作规则，不声称它是某次API请求的逐字系统提示词。当前提炼/复核者是Codex AI会话，精确模型快照未暴露。

## 1. 三个单位必须分清

1. **原文片段**：中文逗号、分号等切出的可追溯文本，不自动等于英语词义。
2. **英语语义/用法**：由具体词典义项、词性、搭配和语境支持；不能仅靠中文相近就合并。
3. **记忆展示单元**：允许把近义解释压缩显示，也允许在同一框架内并列相关用法，但必须保存子义和区别。

例如chop的砍木材、切碎食物在WordNet中有两个词义，不能判成完全相同；首屏可以显示“砍（木材）；切碎（食物）”，下层仍保存两个子义及各自引用。correlate的及物/不及物方向亦然。显示单元减少不代表词义记录被删，也不证明记忆效果提高。

## 2. 首次学习重点的选择

- 先检查生活、阅读、表达所需的不同用法，再决定层级；通常1–2组，但不设硬上限。
- 有不同核心功能时分别保留。get的得到、变得、到达、理解不能靠“只留两条”解决。
- 跨词性不合组。major的形容词、名词、动词分别保留；即使中文有关联也不合成一个词性。
- 扩展层表示本次教学顺序，不能自动称为低频；其他层须写明专业、语域、地区或语境限制。没有频率证据就只称“后学建议”。
- 考研词头分类、词典排版顺序、WordNet义项编号和某词共有几个义项，都不能充当义项使用频率或PETS官方重点证据。

## 3. 证据必须对应到结论

- 每个原文解释分别记录具体synset/词典观察，不能把同词性全部WordNet义项挂上去便声称逐义验证完成。
- 标明证据关系：相容、上下位/语境对应、中文范围偏宽、只在语境转述成立、原书词性对应未明等。
- 在一部词典中没有找到，不等于这个义项不存在。abstract的提取、reverse的倒车要允许正规词典补证。
- 同样，“原文列出”也不等于可以安全独立教学。notify的使注意、engage的实行，不能因保留原文就默认是另一个可靠义项。
- 遇到词典分歧或覆盖不足，保留不确定性。garbage所选WordNet义较窄，不足以据此否定中文垃圾的日常范围。

## 4. 原文含义不明时的处理

- 保留全部原文，不把疑点偷偷放到“其他义”冒充已确认但少见。
- 不能独立支持的原解释进入 `reserved_original_items`，记录原文ID、理由和证据。
- 像obvious的无疑的，可标为特定语境中文转述，不另造一个英语“确定无疑”义项。
- 原文只列多词性、没有逐义标签时，保持原始对应未知。knock可基于独立英语证据推荐动词敲/碰撞，但不得声称已查清原书名词排序。

## 5. 词义缺口与新增内容分离

- 对已有样本做“是否缺少重要用法”的检查，但不穷举词典所有生僻义。
- 仅有原文覆盖率100%，不能证明没有漏掉run的运转、chair的主持、priority的优先事项等。
- 来源外补充一律单列 `dictionary_addition_candidates`，有独立证据、建议层级及理由；`source_sense_ids=[]`，不能冒充原书已有内容。
- 中文同一语义的改述也要标明AI改述来源，不声称原书逐字写了新措辞。语境收窄或扩展必须说明范围。
- 新增候选只限已选定100个词头；规则中的issue/charge/address不是自动扩充样本的授权。

## 6. 审核状态与工程约束

- AI复核、真人内容裁定、结构校验、学习效果实验分开记录，不互相替代。
- 同一AI会话的第二轮非盲审不能称为第二个独立模型或独立真人结论。
- 用户未提出修改不等于语言学签审；也不要求初学者替系统承担专业语言判断。
- confidence只作为模型自评，不单独用于通过/排序/发布。没有人工金标准就不报告准确率提升。
- 新版本绑定原输入字节哈希、原逐词决定哈希、复核决定哈希和证据/规则版本。
- 校验100个ID范围、全部原文片段、词性边界、子义保留、证据所属词头、增义来源及统计；损坏或源漂移立即拒绝，不能自动覆盖旧成果。
- 正式CSV、SQLite、Notion、学习事件/复习日期均不属于复核脚本写入范围。普通构建和校验不发起模型API或词典抓取。

## 7. 合法来源和失败记录

WordNet文本按项目已有许可引用。受版权保护的网页只保留短篇原创概述及URL，不复制整页或大量词典例句。直接读取403时如实记录；使用搜索服务已有公开索引摘要时明确其局限，不冒充实时整页读取，不绕过限制。自行编写的搭配/例句标为教学例示，不冒充语料命中或统计。
